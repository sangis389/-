# SCM Weekly Dashboard

`OMH_SCM_Weekly_Report` 주간 보고 엑셀(시트 ①~④)을 올리면 바로 주간 보고용 대시보드로 보여주는 정적 웹페이지입니다.
설치·서버·Python 없이 브라우저만으로 동작하며, 파일은 서버로 전송되지 않고 브라우저 안에서만 읽습니다.

## 사용법

1. `index.html` 을 엽니다. (GitHub Pages로 배포하거나, 로컬에서 바로 열어도 됩니다)
2. **엑셀 업로드** 버튼을 누르거나 파일을 창에 끌어다 놓습니다. 여러 국가·여러 주차 파일을 한 번에 올릴 수 있습니다.
3. 상단에서 **국가 / 주차**를 고르고 탭을 넘기며 보고합니다. `더보기 → 인쇄 / PDF 저장` 으로 전 탭을 PDF로 뽑을 수 있습니다.

올린 데이터는 이 브라우저(localStorage)에 저장되어 매주 올릴수록 **주차 추이**가 쌓입니다.

## 화면 구성

| 탭 | 엑셀 시트 | 내용 |
|---|---|---|
| ① 주간 실적 | ① 주간 내역 | KPI 타일(RN·Revenue·Cost·Margin·Margin Rate, WoW/MoM/YoY), 비교표, 지역별 RN·WoW 차트와 표, Top 10 호텔, 독점/HB 기여도 |
| ② 신규·급감속 | ② 신규 예약 호텔 | 신규 호텔 / 급감속 호텔 / 급감속 지역. 시트가 비어 있으면 ①의 데이터로 자동 산출(태그로 표시) |
| ③ HB·Floating | ③ HB.Floating Status | 호텔별 연간 요약, 호텔 선택 → 월별 RN·Margin 차트와 월별 표, 개별 호텔 합산 계산값 |
| ④ 시장·경쟁사 | ④ Market & Competitor Trends | 지역별 시장 이슈, 경쟁사 이슈 |
| 주차 추이 | (누적) | 저장된 주차별 RN·Margin·마진율 추이, 국가별 최신 주차 요약 |
| 데이터 점검 | 전체 | 합계 불일치, 하드코딩 수식, 복사 오류, 미입력 항목 자동 점검 |

**마진율 기준**: 원본 엑셀은 총 실적 마진율을 *원가 대비(Margin ÷ Buying)*, 지역·호텔은 *매출 대비(Margin ÷ Selling)* 로 계산합니다.
대시보드는 상단 선택값 하나로 모든 화면을 통일해 보여줍니다.

## 엑셀 양식 규칙

파서는 셀 좌표가 아니라 **제목/헤더 텍스트**로 표를 찾으므로 행이 추가·이동돼도 동작합니다. 다음 텍스트만 유지해 주세요.

- ① `Country: <국가명>`, 기간 셀(예: `2026.24 - 25-Sep`), `Metric / This Week / Previous Week` 헤더, `Region/City` 헤더(마지막 `Total` 행), `Hotel Name` 헤더, `Exclusive / Hard Block` 제목
- ② `신규`, `급감속 호텔`, `급감속 지역` 제목 + 바로 아래 `#` 헤더
- ③ 블록마다 `코드 - 호텔명` 제목, `Values | Jan … Dec` 헤더 (`(Floating)` 같은 괄호는 유형 태그로 표시)
- ④ `Region/City | Market Notable Issues`, `Competitor | Description` 헤더

같은 국가·같은 기준일 파일을 다시 올리면 덮어씁니다. 기준일은 기간 셀의 `25-Sep` 에서 읽고, 없으면 파일명 끝 `_0925` 에서 읽습니다.

## 팀 공유 (선택)

`더보기 → 데이터 내보내기` 로 받은 `reports.json` 을 `data/reports.json` 에 커밋하면, 페이지를 여는 모든 사람에게 그 데이터가 자동으로 로드됩니다.
**실적 금액이 그대로 들어가므로 저장소가 비공개(Private)인지 먼저 확인하세요.** 원본 엑셀(`*.xlsx`)은 `.gitignore` 로 커밋되지 않습니다.
